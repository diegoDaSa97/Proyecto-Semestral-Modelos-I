# Proyecto Integrador – Modelos y Simulación de Sistemas I

Proyecto acumulativo para llevar un modelo de Machine Learning desde un notebook hasta un prototipo desplegable.
Problema: predicción de fuga de clientes (*Telco Customer Churn*, Kaggle).

| Fase | Contenido | Carpeta | Estado |
|------|-----------|---------|--------|
| 1 | Modelo predictivo (notebook, modelo, README) | [`fase-1/`](fase-1/) | Completada |
| 2 | Scripts (`train.py`, `predict.py`), Docker y pruebas | [`fase-2/`](fase-2/) | Completada |
| 3 | API REST | `fase-3/` | Pendiente |
| 4 | Monitoreo básico | `fase-4/` | Pendiente |

Cada fase conserva y amplía el trabajo de la anterior.
